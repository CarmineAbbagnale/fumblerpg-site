# Fumble RPG: sito ufficiale

Pagine del sito di Fumble RPG, l'app companion per D&D 5a edizione e Pathfinder 2a edizione.

- Home: https://carmineabbagnale.github.io/fumblerpg-site/
- Scarica l'app: https://carmineabbagnale.github.io/fumblerpg-site/la-mia-app/
- Copia PWA dell'app (cartella `app/`): https://carmineabbagnale.github.io/fumblerpg-site/app/

Hosting statico su GitHub Pages, nessun backend. I contenuti dell'app (motore di gioco) vivono nel repository separato `rollone-desktop`.
